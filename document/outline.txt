  Baseline offset-free Koopman MPC using an LTI lifted model, a Kalman filter, a linear target problem, and a linear MPC problem.

4. Methodology
  Proposed scheme: keep the MPC cost in lifted space and linearize the nonlinear output map only where the original coordinates are still needed (targets and constraints).

  4.1 Linearization of Output Mapping
    First-order Taylor linearization of h(z) at either the previous target or the current state estimate.

  4.2 Target Optimization
    Steady-state target problem with the linearized output map, using the previous target as the linearization point.

  4.3 MPC
    Receding-horizon problem with cost on lifted-state error (Qz derived from Qy and the Jacobian) and linearized output constraints.

  4.4 Closed-Loop Control Structure
    Two algorithms: linearize at the previous target, or linearize at the current Kalman estimate, then observer → target → MPC.

  4.5 State Estimation - Time Varying Kalman Filter
    Time-varying Kalman filter on the disturbance-augmented lifted state, with the measurement equation re-linearized at each sample.

  4.6 Block Diagonal Deep Koopman Transformation
    Similarity transform of A (and B, C, z, Jacobian) into block-diagonal form to speed up the QP and raise the rate of optimal solves.
